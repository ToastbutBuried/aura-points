# Commands

All under `/aura` unless noted. Tab completion shows everything your permission level allows. Who may use which command is set in `aurapoints-commands.json`.

## Players
| Command | What it does |
|---|---|
| `/aura book`, `/aura menu` | get or open the Aura Book |
| `/aura roll` | roll an aura (always one you never had) |
| `/aura switch <aura>` | go back to an aura you had |
| `/shop` | buy abilities |
| `/aura redeem` | buy skill points |
| `/aura info` | your aura's details, casts and chains |
| `/aura mastery` | Mastery levels and XP |
| `/aura branch` | pick or change your branch (Mastery V) |
| `/aura awaken`, `/aura altar` | the Awakening Altar (`/aura altar lore <aura>` = the Keeper's story) |
| `/aura trial` | the Aura Trial (`/aura trial stop`) |
| `/aura loadout` | loadout presets |
| `/aura relic`, `/aura relics` | buy, reroll and wear relics |
| `/aura cosmetics` | cosmetics |
| `/aura weekly` | weekly challenges |
| `/aura reactions`, `/aura combos` | what reactions and team combos exist |
| `/aura bloom`, `/aura nightvision` | switch those passives |
| `/aura arena` | arena: `join`, `leave`, `duel`, `match`, `spectate` |
| `/aura leave` | leave any arena activity |
| `/aura ticket` | write a ticket (`/aura tickets` for reviewers) |
| `/changelog` | what is new |

## Admins
| Command | What it does |
|---|---|
| `/aura reload` | reload every config file |
| `/aura give`, `/aura setaura` | give Aura or items, set an aura |
| `/aura mastery set ...` | set Mastery levels |
| `/aura resetprogress` | reset parts of a player's progress |
| `/aura balance` | the Balance Tome |
| `/aura worthy` | who may wield Mjölnir and the weapons |
| `/aura handheld`, `/aura mjolnir` | give the aura weapons |
| `/aura storm`, `/aura shrine`, `/aura rift` | spawn or manage storms, shrines and rifts |
| `/aura bear`, `/aura frostbear` | the Frost Bear |
| `/auradev ...` | development test commands (only in dev builds) |

# The Aura Book

Everyone gets an **Aura Book** (lost it? `/aura book`, or craft a book with an amethyst shard). Right-click it, or use `/aura menu`, for everything the mod offers:

- your aura, its abilities (buy them right there), Mastery and branch,
- rolling and switching ([details](rolling-and-switching.md)),
- skill points, cosmetics, weekly challenges, loadouts, relics,
- an **Earn Aura** page with every way to get Aura and a button for the quest book ([QUESTS.md](../../QUESTS.md)),
- the Aura Trial ([details](aura-trial.md)),
- settings.

Every ability entry lists its sneak and charged casts and the chains that end on it. A short tutorial runs until you finish it or pick "Don't show again". Every button also works as a command (`/aura ...`).

Server owners get the **Balance Tome** (`/aura balance`) to edit balance values in game.

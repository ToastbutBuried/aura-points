# Local storms

A few weather cells drift across the overworld, **one per aura**. Inside one, the matching aura deals more damage and has shorter cooldowns, everything alive carries the storm's reaction mark ([reactions](reactions.md)), and the storm has a small world effect. They appear on your screen as fog, a tinted sky and a curtain wall seen from outside (client option `stormWalls`).

| Storm | Aura | Mark |
|---|---|---|
| Thunderhead | Thunder | Charged |
| Downpour | Water | Wet |
| Blizzard | Frost | Chilled |
| Heat Haze | Fire | - |
| Gale | Wind | - |
| Spore Bloom | Verdant | - |
| Tremor | Earth | - |
| Aurora (night) | Light | - |
| Umbra | Shadow | - |
| Crimson Moon (night) | Blood | - |

Admins: `/aura storm`.

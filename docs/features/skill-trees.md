# Skill trees

Built on [Pufferfish's Skills](https://modrinth.com/mod/skills), shipped inside the mod: an **Aura tree**, an **Ability tree**, and a **PvP tree** that unlocks when you defeat a boss from the `#aurapoints:bosses` entity tag (Wither, Ender Dragon, Warden, Elder Guardian by default). Skill points are bought with Aura (`/aura redeem`). Stunt, feat, combo and reaction **advancements** also ship in the mod.

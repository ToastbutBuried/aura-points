# Aura weapons

Handheld weapons, one per aura, each with a right-click ability. **Owner-only by default**: server owners can make others *worthy* with `/aura worthy add <player>` (the switch is `WORTHY_ENABLED`, the list `aurapoints-worthy.json`). `/aura handheld` gives them to owners.

| Aura | Weapon | Right-click ability |
|---|---|---|
| Water | Leviathan's Anchor | **Maelstrom**: kraken tentacles drag every enemy into a whirlpool, then a giant tentacle slams down |
| Fire | Phoenix Fangs | **Sunfall**: a meteor crashes on the spot you point at, leaving a burning crater |
| Wind | Stormcaller Glaive | **Eye of the Storm**: hurl it as a tornado that sucks enemies in and bursts; the glaive flies back |
| Shadow | Soul Reaper | **Umbral Ambush**: appear behind the nearest enemy, invisible, leaving a shadow clone |
| Frost | Absolute Zero | **Winter's Gate**: a wall of spiked ice that stops projectiles, freezes, then shatters |
| Thunder | Zeus Gauntlets | **Chain Strike**: flash from enemy to enemy as lightning, a giant bolt on the last |
| Verdant | World Tree Bow | sneak + right-click shoots a seed that grows a **Thorn Sentinel** tree |
| Thunder | **Mjölnir** | a hammer: hold Swing to whirl it, throw it and steer it in flight |

Damage and cooldowns live in `aurapoints-handhelds.json`.
